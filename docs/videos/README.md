- [Vertical MP4](./magi-demo-vertical.mp4): 1080×1920, same duration and codec. The MAGI display retains its 4:3 ratio.

- [Share image example](./share-card-example.png): 1200×1600 PNG generated by the same review-and-export button available in the app. Uses a short, editable editorial headline/conclusion and a link to the exact public verdict. The original question and report are unchanged.
- [Machine-readable provenance](./provenance.json).

The footage replays an **actual Codex deliberation** created specifically for this public demonstration. The fictional proposal asks whether to add an untested feature to a hobby app two days before a demo. All 12 public assessments and the final synthesis are preserved in [the sanitized recording](../../demo/recordings/public-run.json). MELCHIOR approves with conditions; BALTHASAR and CASPER deny. The recorded vote is 2–1 DENIED. No disagreement or outcome was forced.

The recorded session lasts approximately 85.8 seconds. The video uses edited timing and holds selected frames; its 25-second length is not an inference-speed measurement. Account usage counters are redacted to zero for rendering, and original session/run identifiers are removed. No personal decision history, auth data or original model trace is included. The public demo identifies this recording separately from its three authored illustrative examples.

The first 2.6 seconds, including the dissolve, compare frame 71 from the original Evangelion TV-series UI with this fan recreation in the same 4:3 display area. The [reference archive](https://gwern.net/doc/anime/eva/2017-10-13-ui99nkgbt-imgur-neongenesisevangelionuserinterfacescreenshots.zip) is credited on-screen. The original standalone PNG is not included in the repository. Original imagery and franchise marks remain subject to their owners’ rights, separately from the software MIT license. No original music or audio is used.

## Reproduce the exports

```sh
npm run build:demo
npm run video:demo -- --reference /absolute/path/to/your/reference.png
# Or omit the TV-image comparison:
npm run video:demo -- --without-reference
npx tsx scripts/capture-demo-assets.ts
```

Requires Chromium (`npx playwright install chromium`) and `ffmpeg`. These exports replay the already-public recording and make no new model calls. `scripts/record-public-demo.ts --record` is a separate, explicit operation using 13 actual model calls; builds and CI never run it.
