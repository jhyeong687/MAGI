- 답변은 짧은 결론·최대 세 가지 행동·핵심 반론을 먼저 보여주고 전체 답변과 인격별 원문을 접어 둔다. 기존 기록은 첫 문장과 저장된 조건·반론으로 표시하며 원본과 표를 변경하지 않는다. 새 응답에는 같은 최종 보고서 호출에서 구조화된 요약을 요청한다. 과거 형식은 그대로 읽으며 새 요약을 위해 자동 재생성하지 않는다. 실제 모델의 새 요약 작성은 비용 제한에 따라 이번 검증에서 호출하지 않았다.
- 진행 안내는 현재 단계·회차의 실제 응답만 세고 기다리는 인격을 표시한다. 실시간 경과·마지막 응답 시간과 재생 기록 시점을 구분하며 보고서 단계의 최종 표·작성 상태를 별도로 표시한다. 실패·중지·보고서가 없는 과거 기록을 완료로 오인하지 않도록 검사했다.
- 중앙 SVG, 일본어 명판·판정 연출, 정면 4:3 도형과 불규칙 점멸은 변경하지 않았다. 새 조작부와 안내는 그림 바깥에 배치했다. 질문 도우미, 실제 응답 대기, 모바일 요약과 전체 화면 이미지를 다시 촬영했다.
- 병렬 검사에서 로컬 결과 폴더가 데모 결과 폴더를 지우던 충돌을 확인했다. `test-results/local`과 `test-results/demo`로 분리한 뒤 두 전체 검사군을 동시에 실행해 통과했다.

## 자동 검증

```sh
npm ci
npm test
npm run build
npx playwright install chromium
npm run test:browser
```

GitHub Actions는 Linux의 Node 22/24에서 단위·빌드 검사를, Node 24에서 Chromium 브라우저 검사를 실행한다. 실제 모델 호출이나 ChatGPT 인증은 필요 없다. macOS arm64에서도 검증했다. native Windows 동작은 보장하지 않으며 WSL2 사용을 안내한다.

## 화면 재현

```sh
npm run screenshots
```

Chromium과 GIF 생성을 위한 `ffmpeg`가 필요하다. 실행 중인 브라우저 테스트가 있다면 먼저 종료하라. `docs/screenshots/`에 메인, 로그인, 독립 분석, 상호 검증, 토론 기록, 인격 상세, 설정, 최종 답변, 모바일과 처리 GIF를 저장한다. 예시 데이터와 시간은 문서 작성용이며 실제 모델 결과나 속도 측정값이 아니다.

## 실제 Codex 검증

출시 준비 과정에서 공식 프로젝트 의존성 Codex CLI의 버전·격리 플래그·ChatGPT 인증 감지와 구조화 출력을 확인한다. 초기 구현에서는 실제 심의의 독립 분석 → 상호 반박 → 재검토 → 최종 투표 → 종합 답변까지 실행하고, 세 thread와 별도 보고 컨텍스트·응답 수·투표 보존을 확인했다. 개인 실행 원본은 공개하지 않는다.

직접 재현하려면 로그인한 상태에서 로컬 서버를 시작한 뒤 아래 명령을 실행한다.

```sh
npm run verify:live
```

기본 **13회 실제 호출**을 사용하고 해당 계정 한도가 차감된다. 결과는 Git에서 제외된 `docs/evidence/`에 저장한다. 테스트를 통과했다는 것이 모델 판단의 정답성·원작의 완전한 시각 복제·모든 계정과 OS의 호환성을 보장하지는 않는다.
