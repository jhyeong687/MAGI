# TV판 화면·처리 연출과 수정 검증

2026-10-28. 현재 구현과 검증 범위를 기록한다.

## 참고 자료와 비율

- [에반게리온 공식 TV 시리즈 Blu-ray 사양](https://www.evangelion.jp/news/eva_bdboxse/)은 TV 시리즈 HD 리마스터를 **1080p / 4:3**로 명시한다. 과거 구현에서 704×480 캡처의 저장 픽셀 비율을 표시 비율로 사용했던 것을 수정했다.
- [TV 시리즈 캡처 보존본](https://gwern.net/doc/anime/eva/2017-10-13-ui99nkgbt-imgur-neongenesisevangelionuserinterfacescreenshots.zip)의 `71 - SysmwHd.png`는 정면 진단 화면의 기준이다. `74`, `72`, `82`, `84`번 캡처로 다각형 연결 구조·색·이름·도장을 확인했다. 카메라의 기울기를 복사했던 버전은 사용자 피드백에 따라 교체했다. 현재 심의 화면은 같은 연결 구조를 유지한 **대칭적인 정면 화면**이다.
- 원본은 `.research/reference-frames/`에만 보관한다. 제품에는 직접 작성한 SVG/CSS와 합성 음만 사용한다. 원작 PNG·음악·음원을 본체 자산으로 복사하지 않는다. 공개 시연 MP4의 도입부에만 71번 TV 참고 프레임을 최대 2.6초 동안 대조·겹침 전환으로 사용한다. 출처를 영상과 `docs/videos/README.md`에 표기하며 원본 음원은 사용하지 않는다.

SVG 표시 영역은 640×480이다. 캡처에서 잰 704×480 좌표를 가로 10/11로 보정하는 정책을 적용해 TV 4:3로 보여준다. 이는 공식 표시 비율에 맞추기 위한 정규화이며 보존 PNG의 원래 픽셀 종횡비 메타데이터를 확인했다는 뜻은 아니다. 화면 비율은 모든 뷰포트에서 유지하며 남는 부분은 검정 여백으로 둔다. 패널·표제·도장·연결선은 동일 좌표 평면을 사용한다.

## 장면과 실제 처리

| 서버 상태      | 화면과 동작                                                                                             |
| -------------- | ------------------------------------------------------------------------------------------------------- |
| 대기/호출 준비 | 빈 패널, 待機中 또는 審議中. 실제 응답이 없는 코어를 완료로 채우지 않음                                 |
| 독립 분석      | 71번 캡처의 원형 연결망과 고정 사각 패널. 위치·각도는 움직이지 않고 실제 응답이 온 패널만 녹색으로 채움 |
| 상호 검증      | 원작의 다각형을 정면에서 보는 대칭 배치. 대기 코어만 청색/검정 점멸, 연결선에 신호가 이동               |
| 재검토         | 같은 심의 구도에 코어 스캔과 느린 연결 신호. 실제 응답 도착 시 해당 코어 점멸 중지                      |
| 최종 투표      | 실제 최종 표가 도착한 코어부터 녹색/적색/기권색 고정                                                    |
| 최종 보고      | 세 표를 모두 받은 뒤 可決 / 否決 / 保留와 결과 컷. 기존 요청대로 2/3 다수결                             |
| 중지/오류      | 中止 / 障害. 늦은 응답을 버리고 가짜 최종 표나 완료를 만들지 않음                                       |

실제 처리는 서로 다른 Codex thread 3개에서 독립 분석 → 상호 검증 → 재검토 → 최종 투표로 진행한다. 각 단계의 세 응답을 모두 받은 후 다음 단계에 공유한다. 세 인격은 같은 기반 모델을 사용할 수 있으며 의견 차이를 강제하지 않는다. 이 과정은 사용자가 정한 5단계 프로토콜이다. 원작 속 메모리 검사·사도 침식·자폭을 실제 기능으로 가장하지 않는다.

서버 발행 시점의 단계·코어 상태·응답 수·사용량·오류·세션 ID·종합 답변 상태를 기록한다. 다시보기는 해당 시점까지 실제로 도착한 정보만 보여준다. 사각 패널에 덧붙였던 회전 연출은 사용자 요청으로 제거했다. 점멸·신호는 재생 위치를 따른다. 종합 답변은 생성이 끝난 프레임에서만 표시한다. 옛 기록에 나중에 답변을 추가한 경우, 두 처리 사이의 긴 유휴 시간은 건너뛴다. 원래 단계의 순서와 처리 시간은 유지한다.

전자 효과음은 Web Audio로 합성한다. 기본 OFF이며 사용자 조작으로 켜야 한다. 실제 단계·응답·종료 변화에만 소리를 내고, 일시정지·과거 탐색·숨겨진 탭에서는 새 이벤트 소리를 재생하지 않는다. 원본 녹음의 복제가 아니다. reduced-motion과 애니메이션 OFF를 존중한다.

## 버그 수정

- 704:480 저장 픽셀 비율을 4:3 TV 표시 비율로 수정.
- 화면 전체의 카메라 기울기·원근 왜곡을 제거. 표제·코어 이름·도장·연결선을 수평으로 정렬하고 패널이 잘리지 않도록 프레임 안에 배치.
- 재생 시작 시 최종 시간·토큰·오류·세션 정보가 먼저 보이던 오류 수정.
- 모달을 ESC로 닫을 때 화면 전용 모드까지 종료되던 오류 수정.
- 다른 탭에서 새 심의를 시작/종료/중지하면 자동 감지. 과거 기록을 고정한 탭은 선택을 유지하고 새 실행 알림을 표시.
- 재접속 시 다른 새 실행이 있더라도 연결이 끊긴 동안 끝난 고정 기록을 새로 가져옴.
- 비동기 기록 선택과 초기 요청이 새 선택을 덮어쓰는 경쟁 상태 방지.
- 화면 전용 모드에서도 아래 조작부로 중지·재생·기록·설정·음량·종료 가능.
- 운영 5173 서버를 재사용하던 브라우저 테스트를 별도 5187 서버·OS 임시 저장소·테스트 전용 실행기로 분리. 설정 복원에 의존하지 않고 처음부터 운영 데이터에 쓰지 않음.

## 검증 방법과 한계

`npm test`는 투표 27개 조합, 세션 격리·라운드 공유·중지·오류·타임아웃·JSONL·API·SSE·재생 메타데이터를 검증한다. `npm run test:browser`는 데스크톱/모바일과 1920×1080 / 1440×900 / 1280×720 / 390×844 / 844×390 비율, 기록·설정·재생·ESC·다른 탭·재접속·접근성·소리 동작을 확인한다. 모델 사용량을 쓰지 않는다.

비율 유지 테스트와 별개로 `scripts/qa/reference-fit.py`가 실제 원본 PNG의 주황/적갈색 윤곽 픽셀을 추출해 진단 장면의 패널 경계와 거리를 비교한다. 300개 표본의 평균은 **0.82 저장 픽셀**, 95백분위는 3.21px이다. 심의 장면은 정면으로 재구성했으므로 기울어진 카메라 캡처와 직접 픽셀 오차를 비교하지 않는다. 대신 패널 대칭·수평/수직 경계·프레임 내부 배치와 모든 표제·이름·도장의 수평 상태를 검증한다. 수치는 로컬 개발 검증에서 산출했다. 원본 캡처와 실행 산출물은 공개 저장소에 포함하지 않는다. 원작을 포함한 진단 대조 이미지는 로컬 `.research/reference-comparison.png`에만 남긴다.

이 수치는 **세 패널 윤곽**의 정합도이며 화면 전체의 픽셀 일치율이 아니다. 서체는 OS의 일본어 글꼴, 색은 캡처 팔레트, 움직임은 실제 AI 이벤트에 맞춘 재구성이다. 원본 영상의 모든 프레임·정확한 동작 타이밍·원본 사운드와 완전히 동일함을 주장하지 않는다. 최신 테스트 개수와 실제 실행 증거는 [VERIFICATION.md](./VERIFICATION.md)에 기록한다.
