## 起動

質問補助で **プロジェクト / 進路 / 日常の選択** を選び、状況・判断したい選択・重視する条件を編集できる。既存の下書きを保持し、自動実行しない。公開デモでは下書き作成とコピーのみ。進行中は現在の段階で受信した応答数、待機中の人格、経過時間を示す。回答は **短い結論 → 最大三つの行動 → 主要な異論** を先に表示し、全文と根拠を展開できる。既存記録は再生成せず保存内容から抜粋する。

Node.js 22以上、npm、インターネット接続とCodexを利用できる自分のChatGPTアカウント・ワークスペースが必要。macOS/Linux、WindowsではWSL2を使用する。

```sh
git clone https://github.com/jhyeong687/MAGI.git
cd MAGI
npm ci
npm run setup
```

公式Codex CLIはプロジェクトに含まれる。未ログインなら公式の認証画面が開く。認証後にビルドとローカルサーバーの起動が続く。[http://127.0.0.1:5173](http://127.0.0.1:5173)を開く。次回は`npm start`で起動できる。アプリの「ChatGPTでログイン」から接続してもよい。

## 言語

初期表示は日本語。画面上部の **言語** から表示言語を切り替えられる。English / 한국어 / 日本語 / 中文の四言語に対応する。メニュー、進行案内、ログイン案内が切り替わり、次の審議から応答もその言語になる。保存済みの質問・応答を自動翻訳して書き換えることはない。

## 実際の処理

独立した三つのCodexスレッドで、独立分析 → 相互反論 → 再検討 → 最終投票を行う。2票以上の賛成で承認、2票以上の反対で否決、それ以外は保留。最後に実際の判断と討論から回答・条件・意見の相違をまとめる。

- MELCHIOR-1：科学者の側面。証拠、因果、成立条件。
- BALTHASAR-2：母としての側面。関係、保護、責任。
- CASPER-3：女性・個人としての側面。欲望、愛着、自分の選択。

4:3の正面画面、固定診断パネル、不規則な処理点滅、公開討論、検索可能な履歴、追加呼出し不要の再生、回答のコピーと保存に対応する。原作の雰囲気を保つため、「提訴」「決議」、状態印、決議演出とシステム銘は、どの表示言語でも日本語のまま固定される。

ローカル版の基本審議は**13回の呼出し**を使い、自分のアカウントの利用枠に計上される。無料クラウド版も最大13回だが、短い出力と共有の日次上限を持つ別のGLM-4.7-Flashモデルである。
