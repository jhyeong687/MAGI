# MAGI // Three Minds. One Decision.

**에반게리온에서 영감을 받은 삼인격 의사결정 콘솔. 각자 자신의 ChatGPT 계정으로 실행한다.**

[English](./README.md) · [日本語](./README.ja.md) · [中文](./README.zh-CN.md) · [설치·로그인](./docs/INSTALLATION.md) · [화면 둘러보기](./docs/INTERFACE.md) · [인격 설정](./docs/PERSONAS.md) · [검증](./docs/VERIFICATION.md)

![MAGI 관제 화면](./docs/screenshots/desktop.png)

> 화면과 GIF는 설명용 예시 데이터로 촬영했다. 실제 모델의 답변이나 처리 시간을 재현한 기록은 아니다. 제품을 실행하면 로그인한 사용자의 Codex가 실제로 분석·토론·투표한다.

MELCHIOR-1, BALTHASAR-2, CASPER-3가 서로 분리된 Codex 세션에서 질문을 분석한다. 서로의 의견을 검토하고 반박한 뒤, 최종 투표와 종합 답변을 메인 화면에 표시한다. 일반적인 채팅창 대신 큰 정면 **4:3 MAGI 화면**, 일본어 표제, NERV 표식, 구형 관제 콘솔을 사용한다.

## 바로 시작하기

**필요한 것:** Node.js 22 이상, npm, 인터넷 연결, Codex를 이용할 수 있는 본인의 ChatGPT 계정·워크스페이스. macOS/Linux에서 실행하며 Windows 사용자는 WSL2 안에서 설치한다. native Windows는 검증하지 않았다.

```sh
git clone https://github.com/jhyeong687/MAGI.git
cd MAGI
npm ci
npm run setup
```

`setup`은 다음을 차례로 수행한다.

1. 프로젝트에 포함된 공식 Codex CLI를 확인한다. 별도 전역 설치가 필요 없다.
2. 아직 로그인하지 않았다면 OpenAI의 로그인 화면을 연다. **사용자 자신의 ChatGPT 계정으로 로그인한다.**
3. 화면을 빌드하고 로컬 서버를 시작한다.
4. 터미널에 표시된 [http://127.0.0.1:5173](http://127.0.0.1:5173)을 연다.

이미 로그인했다면 다음부터는 `npm start`로 실행하면 된다. 서버를 먼저 열고 앱의 **ChatGPT로 로그인** 버튼으로 연결해도 된다. 종료는 터미널에서 `Ctrl+C`다.

```sh
npm start                 # 빌드가 없으면 첫 빌드를 수행한다
npm run login             # 공식 브라우저 로그인
npm run login -- --device # 브라우저 콜백을 쓸 수 없는 환경의 기기 코드 로그인
npm run doctor            # CLI 버전·인증·필수 기능 점검 (모델 호출 없음)
```

기기 코드 로그인은 계정/워크스페이스에서 허용되어 있어야 한다. 설치 오류·포트 변경·계정 변경은 [자세한 설치 가이드](./docs/INSTALLATION.md)를 참고하라.

**언어와 원작 화면:** 상단에서 English / 한국어 / 日本語 / 中文를 선택한다. 메뉴·설명·새 분석·토론·답변은 선택 언어를 따르며, 중앙 MAGI의 「提訴」「決議」와 대기·처리·판정 인장, 판정 연출·시스템 명판은 항상 일본어를 유지한다.

**배포 형태:** GitHub에서 내려받아 각자의 컴퓨터에서 실행하는 앱이다. GitHub Pages만으로 AI 심의를 실행할 수는 없다. 이 버전은 한 서버에 여러 사람의 계정을 모아 운영하는 웹 서비스가 아니다.

## 언어 선택

처음 설치하면 일본어로 시작한다. 상단의 **言語 / Language**에서 **English / 한국어 / 日本語 / 中文**를 바로 선택할 수 있다. 주변 메뉴·처리 상태·로그인 안내가 바뀌고, 새 심의의 분석·토론·최종 답변도 선택한 언어로 생성된다. 저장된 과거 질문과 응답은 원문을 유지한다. 중앙 MAGI의 提訴 / 決議와 상태·판정 인장, 판정 연출은 언어와 관계없이 일본어로 고정한다.

## 무엇이 실제로 돌아가는가

```text
질문 입력
   ↓
독립 분석       세 인격이 서로의 의견을 보지 않고 판단
   ↓
상호 반박       같은 단계의 세 응답을 모두 모아 교환
   ↓
재검토          자기 이전 판단과 동료 반론을 비교
   ↓
최종 투표       APPROVE / DENY / ABSTAIN
   ↓
고정 규칙 집계  2표 이상 찬성 → 승인 · 2표 이상 반대 → 거부 · 그 외 → 판단 유보
   ↓
최종 답변       실제 토론·표결을 근거로 결론, 조건, 남은 의견 차이를 종합
```

- 세 인격은 별도 thread를 유지한다. 같은 기반 모델을 쓰므로 서로 독립적인 세 종류의 모델이라는 뜻은 아니다.
- 모든 인격이 실제 응답을 마쳐야 다음 단계로 넘어간다. 특정 찬반 비율이나 합의를 강제하지 않는다.
- 응답 오류를 기권이나 반대표로 바꾸지 않는다. 인격 평가 중 실패하면 가짜 판정을 만들지 않는다.
- 종합 보고는 네 번째 표를 행사하지 않는다. 보고서 생성에 실패해도 이미 완료된 표결은 보존한다.
- 공개 결론·근거·반론을 표시한다. 비공개 내부 추론은 읽거나 공개하지 않는다.

## 세 인격

| 코어        | 원작의 측면                | 판단에서 더 무겁게 보는 것                       |
| ----------- | -------------------------- | ------------------------------------------------ |
| MELCHIOR-1  | 과학자로서의 아카기 나오코 | 증거, 인과, 검증 가능한 조건, 기술적 성립 가능성 |
| BALTHASAR-2 | 어머니로서의 나오코        | 돌봄, 관계의 신뢰, 부담을 감당할 사람과 책임     |
| CASPER-3    | 여성·개인으로서의 나오코   | 욕망, 애착, 자존심, 자기 선택과 거절할 자유      |

찬반표가 같아도 이유는 다를 수 있다. “과학자는 무조건 찬성”, “어머니는 항상 반대” 같은 규칙은 없다. 세 측면의 대응은 원작을 따르되, 현대 질문의 말투와 토론 방식은 앱용 해석이다. 특정 성별이나 모든 어머니의 성격을 일반화하지 않는다. [설정과 해석 범위](./docs/PERSONAS.md)

![불규칙한 처리 점멸 예시](./docs/screenshots/processing.gif)

진단 사각 패널은 고정되어 있고, 이후 처리 중인 파란 코어는 서로 다른 불규칙 간격으로 점멸한다. 실제 응답이 도착한 코어는 상태가 고정된다. 애니메이션 OFF와 reduced motion을 지원하며 효과음은 기본 OFF다.

![최종 판정과 종합 답변](./docs/screenshots/answer.png)

한국어 최종 보고는 **“조건부로 승인한다. 실행 전에 인력과 공간을 확보하라.”**처럼 판정을 통보한다. 단호한 말투가 불확실성이나 소수 의견을 생략한다는 뜻은 아니다.

[화면 가이드](./docs/INTERFACE.md)에 로그인, 독립 분석, 토론, 인격별 근거, 설정, 모바일, 전체 화면을 모두 실었다. [전체 데스크톱 화면](./docs/screenshots/desktop-full.png)도 볼 수 있다.

## 조작 안내

| 조작                         | 동작                                                                                               |
| ---------------------------- | -------------------------------------------------------------------------------------------------- |
| 심의 개시 / `⌘·Ctrl + Enter` | 질문을 실제 Codex에 제출한다. 한 번에 한 심의를 실행한다.                                          |
| 코어 패널 클릭               | 해당 인격의 판단, 근거, 위험, 반론, 확신도를 연다. 확신도는 모델의 자기 보고 값이다.               |
| 최종 답변 ↓                  | 메인 화면의 판정과 종합 답변으로 이동한다.                                                         |
| 답변·판정 복사 / 보고서 저장 | 선택한 실제 답변·표결·조건·세 최종 의견을 복사하거나 Markdown으로 저장한다.                        |
| 판정 기록                    | 이전 질문을 검색하고 결과와 토론을 다시 연다.                                                      |
| 처리과정 다시보기            | 저장된 실제 단계 전환과 응답을 재생한다. 속도·일시정지·시점 이동을 지원하며 추가 모델 호출은 없다. |
| 실행 중지                    | 진행 중인 Codex를 중지한다. 완료된 호출의 사용량은 되돌아가지 않는다.                              |
| 시스템 설정                  | 언어(영어/한국어/일본어/중국어 간체), 토론 1–3회, 제한 시간, 인격 프롬프트, 효과를 설정한다.       |
| ⛶ / ESC                      | 화면 전용 모드로 전환하거나 돌아온다.                                                              |

질문 초안은 해당 브라우저에 저장된다. 새 심의 버튼이나 기록 이동으로 초안을 지우지 않으며, 제출 성공 또는 “초안 지우기”로 비울 수 있다.

## 계정·사용량

**제작자의 계정이나 API 키를 공유하지 않는다.** 로그인과 토큰 갱신·보관은 공식 Codex가 담당한다. MAGI는 로그인 비밀번호나 인증 토큰을 읽어 브라우저로 보내지 않는다. 사용자마다 자신의 PC와 자신의 인증을 사용한다.

이 앱은 API 키 인증을 허용하지 않고 ChatGPT 인증을 확인한다. 계정·워크스페이스에 Codex 사용 권한이 있어야 하며, 사용량은 해당 계정의 한도에 적용된다. 무료·무제한 이용을 보장하지 않는다. [공식 인증 설명](https://learn.chatgpt.com/docs/auth)

| 토론 설정  | 인격 평가 | 종합 답변 | 심의당 호출 수 |
| ---------- | --------: | --------: | -------------: |
| 1회 (기본) |        12 |         1 |         **13** |
| 2회        |        18 |         1 |         **19** |
| 3회        |        24 |         1 |         **25** |

과거 기록의 답변 생성·문체 갱신·수동 재시도는 보고서 1회다. 자동 재시도는 하지 않는다. 실제 소요 시간과 사용량은 질문·응답 길이·계정 상태에 따라 다르다.

## 데이터와 실행 범위

- 설정·질문·공개 토론·답변은 각 사용자의 `.magi/`에 저장된다. 이 폴더, 인증 정보, 개발자의 기록은 저장소에 포함하지 않는다.
- 질문과 판단 요청은 사용자가 연결한 Codex를 통해 모델에 전송된다. “로컬 앱”이 “오프라인 모델”을 뜻하지는 않는다.
- 서버는 `127.0.0.1`에 바인딩하고 Host/Origin을 검사한다. 공개 서버용 회원·권한·계정 분리 계층은 없다.
- 심의는 read-only, shell·추가 subagent·웹 검색·사용자 MCP 설정을 끈 상태로 실행한다. 표결 결과로 시스템 작업을 자동 실행하지 않는다.
- 로그인 실패·취소·중복 요청·연결 끊김을 처리한다. 인증을 완료하지 않으면 심의를 제출할 수 없다.

## 개발과 검증

```sh
npm run dev
npm test
npm run build
npx playwright install chromium
npm run test:browser
npm run screenshots  # 별도 테스트 서버와 예시 데이터. GIF 생성에는 ffmpeg 필요.
```

단위·API·브라우저 검사는 실제 모델을 호출하지 않는다. 브라우저 검사는 별도 **5187 포트**, 임시 저장소와 테스트 실행기를 사용한다. CI도 개인 인증이 필요 없다. [검증 방법과 한계](./docs/VERIFICATION.md)

| 경로                     | 역할                                              |
| ------------------------ | ------------------------------------------------- |
| `src/`                   | React UI, SVG 화면, 재생, 로그인 안내             |
| `shared/`                | 데이터 검증, 투표 규칙, 인격 설정                 |
| `server/codex.ts`        | 공식 CLI 실행·JSONL·구조화 출력·타임아웃          |
| `server/login.ts`        | 로컬 Codex 로그인 시작·상태·취소. 토큰 처리 없음. |
| `server/orchestrator.ts` | 인격별 세션과 단계별 스냅샷, 투표 후 종합         |
| `server/store.ts`        | 원자적 로컬 JSON 저장                             |
| `tests/`                 | 테스트 전용 실행기와 설명용 예시                  |

`npm run verify:live`는 개발용 실제 심의 검사이며 기본 13회 호출을 사용한다. 일반 테스트와 구분해서 실행하라.
